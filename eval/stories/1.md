# add and list

Story 1 of 2 for tally: the shared parts of the program, the commands `add` and `list`, and the
usage check for all four commands. It starts from an empty `app/`.

## What to build

tally is a command-line program in Node.js 22 with no dependencies that keeps named counters in
`tally.json` in the current directory. This story builds:

- **REQ-01** Add to a counter (`tally add <name>`).
- **REQ-02** List the counters (`tally list`).
- **REQ-05** Refuse a missing or unknown command.
- **REQ-06** Check usage before touching the file.
- The usage check of `reset` and `remove` too (REQ-03 and REQ-04 acceptance 6 to 9): `usage.js`
  validates the arguments of all four commands. The `reset` and `remove` command modules are story
  2's; until then a correctly used `tally reset coffee` or `tally remove coffee` exits 1 with one
  `tally: ...` line, because the module is absent (TECH-SPEC section 7, "Between story 1 and story 2").
  Do not create those modules.

## Done means

`sh eval/run.sh` exits 0 from the repository root (all 52 rows on main pass, conventions step
passes). Docker is required: the script runs every step inside the pinned Node 22 container
as your own user, and writes the log to `eval/report/eval.log`. Story 2's rows arrive later in
their own packet. Run it as a non-root user: the
permission rows fail with "P1 not met" when run as root.
