# reset and remove

Story 2 of 2 for tally: the commands `reset` and `remove`. It starts from story 1 merged: `add`,
`list`, `usage.js` (which already validates all four commands), `store.js`, `names.js` and
`errors.js` are complete, and the entry point loads the module of a valid command from
`app/src/commands/<command>.js`.

## What to build

- **REQ-03** Reset a counter to zero (`tally reset <name>`): `app/src/commands/reset.js`.
- **REQ-04** Remove a counter (`tally remove <name>`): `app/src/commands/remove.js`.

Each module holds that command's rule only, with no file access, in the shape TECH-SPEC section 2
gives: it exports `run(counters, name)` over the checked counters (a `Map`), returning the new
counters and the text to print, and `writes` set to true; a missing counter is a
`CouldNotBeCarriedOut` from `errors.js`. It imports `../names.js` and `../errors.js` only. It edits
none of story 1's files.

- REQ-04: T-REQ-04-P1, T-REQ-04-P2, T-REQ-04-N1 to T-REQ-04-N3, T-REQ-04-N8 to T-REQ-04-N14 (12)

Story 1's 52 rows, including the usage rows T-REQ-03-N4 to N7 and T-REQ-04-N4 to N7, must keep

## Done means

`sh eval/run.sh`, run from the repository root, exits 0: the conventions step passes and all 76
rows pass. Docker is required: the script runs every step inside the pinned Node 22 container as
your own user, and writes the log to `eval/report/eval.log`. Run it as a non-root user: the
permission rows fail with "P1 not met" when run as root.
